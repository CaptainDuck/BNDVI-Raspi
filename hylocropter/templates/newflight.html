How to enter this in Mission Planner
  1. Flight Plan tab. Right-click the map → Draw Polygon and trace the block you want surveyed.
  2. Right-click again → Auto WP → Survey (Grid).
  3. In the Simple tab set Altitude to the value above. Tick Advanced Options to reveal the rest.
  4. Set Distance between lines to the line spacing above. Mission Planner may compute its own value from a camera profile — override it with this one, which is based on your actual lens.
  5. Set Camera trigger distance to the photo spacing above. That writes a DO_SET_CAM_TRIGG_DIST command into the mission, which is what makes the Pi take photos.
  6. Set the flight speed to about 3 m/s — fast enough to finish, slow enough that a 5000 µs shutter does not smear.
  7. Accept, then Write the mission to the aircraft.

Alternatively skip the survey tool and set the CAM_TRIGG_DIST parameter directly in Config → Full Parameter List. Same effect, but it then applies to every mission rather than just this one.

Overlap defaults are modest on purpose: this system places each photo by GPS rather than stitching a true orthomosaic, so it needs only enough overlap to avoid gaps when the GPS wanders. If you later switch to real photogrammetry, raise both to 70–80%.
